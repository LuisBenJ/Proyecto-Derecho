# Derecho y Legislación en Informática

Versión corregida y reorganizada del material interactivo.

## Cambios principales

1. Cada unidad ahora tiene una explicación real del **tema principal**.
2. Cada unidad tiene una **ilustración propia**, relacionada con su contenido.
3. Se añadieron **conceptos clave** para estudiar.
4. Los subtemas siguen separados y navegables.
5. Se agregaron fuentes de consulta oficiales en las unidades que requieren marco jurídico.
6. El contenido y la lógica están separados.

## Cómo abrirlo

Puedes abrir `index.html` directamente o usar Live Server en VS Code.

Si usas Live Server, la página debería cargar desde una dirección parecida a:

```text
http://127.0.0.1:5500/index.html
```

## Nota sobre las imágenes

Las imágenes de las unidades son SVG vectoriales creados específicamente para este proyecto. No dependen de imágenes externas, por lo que no se rompen si no hay Internet.
